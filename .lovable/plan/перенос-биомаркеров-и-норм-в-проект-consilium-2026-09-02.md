# Перенос биомаркеров и норм в проект consilium

Готовим самодостаточный пакет миграции: структура таблиц, все данные по 135 биомаркерам и 5 категориям, плюс код логики определения статусов и расчётных показателей. Пакет собирается так, чтобы Lovable в соседнем проекте прочитал его без домыслов и выполнил пошагово.

## Что попадёт в пакет

1. **Схема** — SQL для таблиц `biomarker_categories` и `biomarkers` (все 31 колонка: единицы, категория, порядок, `range_mode`, `age_ranges` JSONB, границы normal/optimal/critical в трёх вариантах — общие, мужские, женские, `aging_weight`, описания) с GRANT и RLS-политиками (публичное чтение, запись только админам).
2. **Данные** — сгенерированные из нашей текущей боевой базы INSERT-ы: 5 категорий и 135 биомаркеров со всеми границами и описаниями, идемпотентно (`ON CONFLICT (code) DO UPDATE`).
3. **Логика норм** — код 1:1 из нашего проекта:
   - разрешение диапазона с приоритетом возраст → пол → общий (`age_ranges` → `*_male/_female` → базовые);
   - 7-сегментная модель статуса (критично низко / риск низко / ниже оптимума / оптимум / выше оптимума / риск высоко / критично высоко) и её цвета;
   - пограничная зона ±5 % со списком исключений;
   - расчётные биомаркеры по формулам (HOMA-IR, Caro, VLDL, LDL Friedewald, AI, MCV, MCH, MCHC);
   - визуальная шкала диапазонов (компонент полосы со сегментами и маркером).
4. **Инструкция** — README с порядком выполнения, проверочными запросами (должно быть 5 категорий и 135 биомаркеров) и правилами проекта: только числовые биомаркеры, единицы СИ, женские цикл-зависимые гормоны (E2, E3, PRG, LH, FSH) исключены.

## Формат выдачи

Одна папка в `/mnt/documents/consilium-biomarkers/`:

```text
README.md                 — инструкция для Lovable, шаги 1-4
01-schema.sql             — таблицы, индексы, GRANT, RLS
02-categories.sql         — 5 категорий
03-biomarkers.sql         — 135 биомаркеров (данные из боевой базы)
lib/biomarkerNorms.ts     — разрешение диапазонов + статусы
lib/calculatedBiomarkers.ts — формулы расчётных маркеров
lib/biomarkerCodeMap.ts   — карта алиасов кодов
components/BiomarkerRangeBar.tsx — шкала диапазонов
```

Плюс тот же README продублируем как единый файл `consilium-biomarkers-bundle.md` со всем содержимым внутри — на случай, если удобнее просто вставить текст в чат соседнего проекта.

## Технические детали

- SQL-дампы генерируем скриптом прямо из текущей базы (`biomarkers`, `biomarker_categories`), с экранированием текста и корректным приведением `age_ranges` к `jsonb`, чтобы не было ручных ошибок.
- Код копируем без изменений, кроме удаления импортов, специфичных для нашего проекта (при необходимости заменяем на локальные типы).
- В README явно фиксируем цветовые токены статусов (`--status-optimal/acceptable/risk/critical`), чтобы шкала выглядела одинаково.
- Модель здоровья (health index, биовозраст, M1–M8) и AI-промпты в этот пакет не входят — по выбранному объёму переноса.
