# Автозаполнение корзины для залогиненного покупателя

## Что увидит пользователь
- Открыл корзину, будучи в кабинете: ФИО, дата рождения, телефон и email уже заполнены из профиля.
- ФИО (фамилия, имя, отчество), телефон и email у вошедшего заблокированы — их нельзя изменить в корзине.
- Над полями строка: «Заказ появится в вашем кабинете · Антон Проханов. Не вы? Выйти».
- Одинаково для всех вошедших, включая сотрудников.

## Подводные камни и решения
1. **Пустые поля в профиле.** Если в профиле нет, например, отчества или телефона, это поле остаётся открытым для ввода (иначе нельзя оплатить). Блокируются только поля, заполненные из профиля.
2. **Дата рождения** подставляется, но остаётся редактируемой (вы не просили её блокировать).
3. **Профиль не меняем.** Введённое в пустые поля уходит только в заказ.
4. **Выход при открытой корзине.** Поля разблокируются и очищаются. Вход другого человека — подставляются его данные.
5. **Медленная загрузка профиля.** Пока данные грузятся, поля временно неактивны, чтобы человек не начал печатать в то, что сейчас заполнится.
6. **Форматы.** Дата переводится в ДД.ММ.ГГГГ, телефон приводится к +7; битое значение не подставляем и поле оставляем открытым.
7. **Адрес выезда и отделение** не подставляем (в профиле их нет; отделение уже запоминается в браузере).
8. **Партнёрская скидка** после подстановки телефона/email проверяется существующей логикой — без изменений.
9. **Допродажа из кабинета** получает то же автозаполнение.
10. **Защита на сервере.** Для вошедшего оплата берёт ФИО, телефон и email из профиля, а не из формы, чтобы блокировку нельзя было обойти. Пустые в профиле поля берутся из формы.

## Технические детали
- `EnergyCart.tsx`: при `cartOpen` — `getSession()` + `onAuthStateChange`; загрузка `profiles` (`first_name, last_name, middle_name, birth_date, phone, email`, fallback `session.user.email`).
- `lockedFields` — набор полей, заполненных из профиля; для них `readOnly` + стиль заблокированного поля; при `SIGNED_OUT` очистка и разблокировка.
- Хелпер `isoToBirthDisplay`, телефон через `normalizePhone` + `isPhoneValid`.
- Строка с именем и «Выйти» (`supabase.auth.signOut()`), стили существующей корзины.
- `energy-create-payment`: при наличии `userId` перезаписать непустые ФИО/телефон/email значениями из `profiles`; задеплоить функцию.
- Проверка в браузере: гость, вход (подстановка и блокировка), частично пустой профиль, выход.
