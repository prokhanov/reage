# Пример расшифровки: карточка биомаркера как в отчёте ReAge

Сейчас в окне примера показатели оформлены по-своему: собственная плитка, короткие подписи «Что это значит» / «Как это может ощущаться» и мало текста. В настоящих отчётах ReAge структура другая и строго заданная промптом. Переносим её в пример один в один.

## Как будет выглядеть карточка

Точно та же карточка, что в отчёте ReAge:

1. Шапка: название показателя, рядом код в скобках, справа бейдж статуса с точкой (Оптимально / Допустимо / Риск / Критично).
2. Шкала ReAge: «Ваш показатель — X ед.», стрелка над цветной полосой, снизу «● Оптимальный диапазон: A – B ед.».
3. Текст разбора по структуре отчёта:
   - образовательный абзац — что это за показатель, зачем он нужен, как связан с другими показателями набора;
   - строка результата: «Ваш показатель 4.72 ммоль/л находится в оптимальном диапазоне. …» (1–2 предложения интерпретации);
   - блок «Что это значит для вас» — только для отклонения: 3–5 пунктов о том, как это проявляется в жизни, и завершающая фраза с отсылкой к разделу «Рекомендации».

Объём как в отчётах: в норме — 2–4 предложения плюс строка результата; при отклонении — развёрнутый абзац плюс полный блок «Что это значит для вас».

## Что меняется в окне примера

- Каждый показатель чекапа получает карточку описанного вида — сейчас часть показателей вообще без описания.
- Остальная структура окна сохраняется: резюме сверху, показатели, рекомендации, кнопка «Добавить в корзину», дисклеймер.

## Техническая часть

- В окне примера переиспользуем готовые компоненты отчёта: `src/lib/reportLab/renderer/BiomarkerCard.tsx` (со шкалой `renderer/BiomarkerScale.tsx` и `ProseMarkdown`), обёртка контента — `<div className="reportlab">` с импортом `src/lib/reportLab/theme.css`, чтобы стили карточек совпадали с отчётом. Собственная разметка карточки в `CheckupExampleReport.tsx` удаляется, `@/components/BiomarkerScale` в этом окне больше не используется.
- В `src/data/checkupExampleReports.ts` поля `meaning` / `feeling` / `commentary` заменяются на одно поле `commentary` — markdown в структуре отчёта (абзац, строка результата, при отклонении — заголовок «Что это значит для вас» и маркированный список). Тексты переписываются для всех 12 чекапов (~90 показателей) в стиле существующих отчётов ReAge.
- Маппер `ExampleMarker` → `ReportBiomarker`: код, название, значение, единицы и уже заданные в файле диапазоны (`normal/optimal/critical`, гендерные поля — `null`), `category` — slug чекапа. Статус и цвет считает сам `resolveStatusBucket`, отдельная логика в примере не нужна.
- Разбор markdown идёт через `ProseMarkdown`, вложенный `prose` не добавляем.
