# Подпись на фото в hero /energy — как на референсе

## Что изменится

Надпись у фото девушки принимает вид с присланного скриншота:

- Текст заглавными буквами: «БОЛЬШЕ ЭНЕРГИИ» / «ДЛЯ ВАЖНЫХ ВЕЩЕЙ» — две строки, выравнивание по правому краю.
- Обычный шрифт интерфейса (не курсив, не рукописный), мелкий кегль, широкие межбуквенные интервалы, спокойный тёмный цвет.
- Под текстом — короткая тонкая горизонтальная линия справа.
- Никакого наклона и никакой плашки; положение — правый верхний угол фото, с отступом.
- На мобильном — тот же вид, кегль и отступы чуть меньше, читаемость сохраняется.

## Технические детали

Файл: `src/components/landing/energy/EnergyHero.tsx`, блок `figcaption` (строки 60–69).

- Убрать `-rotate-6 / md:-rotate-3`, `font-display`, `italic`, `font-light`.
- Задать: `uppercase tracking-[0.22em] text-[10px] md:text-xs font-medium leading-relaxed text-foreground/80`, выравнивание `text-right`, позиция `absolute top-6 right-6 md:top-10 md:right-10`.
- Две строки текста через `<br />` без переноса внутри строки (`whitespace-nowrap` при необходимости).
- Добавить разделитель: блок `mt-3 ml-auto h-px w-16 bg-foreground/30` (либо `border-t hairline`).
- Оставить лёгкую тень текста для читаемости поверх фото.
- Только вёрстка; логика и остальные блоки страницы не трогаются.
