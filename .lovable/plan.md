# Новая главная страница на адресе /

## Что меняем

Сейчас:
- `/` — старая главная (страница мониторинга)
- `/main` — новый лендинг, который мы собирали
- `/main_new` — просто перенаправление на `/`

После изменений:
- `/` — новый лендинг (тот, что сейчас на `/main`)
- `/main_new` — копия старой главной, чтобы она не пропала
- `/main` — перенаправление на `/` (старые ссылки не сломаются)
- `/monitoring` — без изменений, по-прежнему старая главная

## Технические детали

- В `src/App.tsx` меняем маршруты: `path="/"` → `MainNew`, `path="/main_new"` → `Index` (вместо редиректа), `path="/main"` → редирект на `/`.
- Компоненты страниц не трогаем — меняются только адреса.
- Проверяем в браузере: `/` открывает новый лендинг, `/main_new` открывает старую главную, `/main` перенаправляет на `/`.
- После вашей проверки страницу можно будет опубликовать.
