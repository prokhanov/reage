# B2B-страница ReAge

Отдельная страница `/business` для трёх сегментов: корпорации (HR/C-level), клиники и врачи, фитнес/wellness и лаборатории. Никаких повторов главной: не рассказываем «что такое биомаркеры» и «как работает сервис» — только деловая ценность, экономика, интеграция и доверие.

## Логика страницы

Один вертикальный нарратив: проблема бизнеса → почему ДМС/чекапы её не решают → что даёт ReAge → как это выглядит для сегмента → как внедряется → доверие/безопасность → заявка на звонок. Сегменты не разносим по трём страницам, а даём переключатель: контент трёх ключевых блоков меняется под выбранный сегмент.

## Структура секций

1. **Hero** — «Здоровье команды как управляемый актив». Подзаголовок про измеримый биологический возраст и персональные планы. Одна кнопка: «Заказать обратный звонок». Ниже — строка-доказательство: 100+ биомаркеров, 5 систем организма, годовой цикл наблюдения, отчёт с верификацией врача.
2. **Переключатель сегмента** — липкая полоса с тремя вкладками: Корпорации · Клиники · Wellness и лаборатории. Управляет содержимым секций 3, 5 и 7.
3. **Зачем это бизнесу** (меняется по сегменту) — 4 карточки с деловым результатом: удержание ключевых людей и снижение выгорания / рост LTV пациента и повторных визитов / новый продукт поверх текущего трафика.
4. **Почему не ДМС и не корпоративный чекап** — сравнительная таблица ReAge vs ДМС vs корпоративный чекап vs «ничего не делаем» по строкам: что покупается, ранние отклонения, персональный план, динамика в году, вовлечённость сотрудника, отчётность для компании, данные и приватность. Тон фактический, без выпадов в сторону страховых: ДМС покрывает лечение, ReAge управляет риском до болезни.
5. **Кому внутри компании** (меняется по сегменту) — три персоны с их вопросом и ответом: HR-директор, собственник/C-level, медицинский директор клиники.
6. **Что получает компания** — двухколоночный блок: слева — то, что видит сотрудник (личный кабинет, отчёт, ассистент), справа — то, что видит компания (обезличенная агрегированная аналитика по группе, динамика год к году, отчёт для руководства). Явно фиксируем: работодатель не видит персональные данные.
7. **Форматы сотрудничества** (меняется по сегменту) — 3 карточки: корпоративная программа под ключ, партнёрская программа для клиники (ваш врач — наша аналитика), white-label/реферальная модель для wellness и лабораторий.
8. **Как запускаем** — таймлайн из 4 шагов: расчёт и пилот → забор анализов (в вашем городе / выезд) → отчёты и планы за N дней → квартальный обзор динамики.
9. **Доверие и безопасность** — 152-ФЗ, обезличивание, хранение в РФ, врачебная верификация каждого отчёта, юрлицо и документы (ссылки на существующие страницы «Документы» и «Реквизиты»).
10. **FAQ для бизнеса** — 6 вопросов: минимальный объём, сроки, регионы, договор и закрывающие документы, что если сотрудник уволился, чем отличается от ДМС.
11. **Финальный CTA** — «Рассчитаем стоимость под вашу команду» + форма обратного звонка (имя, компания, телефон, размер команды, сегмент). Цен на странице нет.

## Дизайн

Стиль главной, но заметно более «корпоративный» и спокойный: те же токены и градиент `bg-gradient-hero` для акцентов, крупная типографика по правилу читаемости, карточки `bg-card/50` + `border-border/50` + backdrop-blur, мягкие blur-пятна на фоне. Отличия от главной, чтобы страница не выглядела копией: более строгая сетка (крупные асимметричные блоки вместо равномерных сеток 4×), больше воздуха, цифры и таблица как главные визуальные акценты, минимум иллюстраций. Мобильно: таблица сравнения с горизонтальным скроллом, карточки в одну колонку.

## Техническая часть

- Новая страница `src/pages/Business.tsx`, роут `/business` в `App.tsx`, ссылка «Для бизнеса» в шапке и футере лендинга.
- Компоненты в `src/components/landing/business/`: `BusinessHero`, `SegmentTabs`, `BusinessValueBlock`, `VsDmsTable`, `PersonasBlock`, `CompanyVsEmployeeBlock`, `PartnershipModelsBlock`, `OnboardingTimeline`, `TrustComplianceBlock`, `BusinessFaq`, `BusinessCtaForm`.
- Сегмент хранится в локальном состоянии страницы (плюс `?segment=` в URL для рекламных ссылок).
- Форма переиспользует существующий поток заявки на обратный звонок и Telegram-уведомление с UTM; в payload добавляем поля компании, размера команды и сегмента.
- Метрика: цель на отправку формы через существующий хелпер Яндекс.Метрики; UTM берём из `src/lib/utm.ts`.
- SEO: `PageMeta` с title/description под «корпоративная программа здоровья / чекап для сотрудников», один H1, JSON-LD `Service`, добавление URL в `scripts/generate-sitemap.ts`.
- Тексты — заглушки-черновики по смыслу; конкретные цифры и кейсы не выдумываем, оставляем плейсхолдеры для ваших данных.

## Что уточнить перед запуском

Нужны реальные цифры для блока доказательств (сроки отчёта, охват городов, минимальный объём) — без них поставлю нейтральные формулировки без чисел.
