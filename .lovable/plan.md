# Убрать кнопку «Смотреть результаты» в карточке разового чекапа

## Результат

В карточке разового чекапа (страница «Разовые чекапы» в кабинете) больше не показывается кнопка «Смотреть результаты» — как для пациента, так и в режиме «глазами клиента». Остальное на карточке не меняется: этапы, номер заявки, место сдачи, дата, цена, ссылка на подготовку, блок допродажи.

## Что меняется

- В `src/pages/OneTimeCheckups.tsx` удалить блок, который рисует кнопку «Смотреть результаты» (она появлялась, когда статус чекапа — «Результаты готовы» и к записи привязан отчёт).
- Данные отчёта (`analysis_id`) никуда не деваются — убирается только кнопка, доступ к отчётам через другие разделы кабинета сохраняется.

## Проверка

- Открыть страницу «Разовые чекапы» у записи со статусом «Результаты готовы» (например, Орлов) — кнопки нет, карточка выглядит как на скриншоте, но без кнопки.
- Сборка без ошибок.
